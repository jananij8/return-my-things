# Return My Things – Lost & Found Management System

A web-based Lost & Found Management System designed for colleges to manage lost items, found items and claim requests efficiently.

## Features

- Student Registration & Login
- Admin Login & Dashboard
- Staff Management
- Student Management
- Report Lost Items
- Report Found Items
- Lost Item Management
- Found Item Management
- Claim Request Management
- Approve / Reject Claims
- Item Image Upload
- Excel & PDF Reports
- Dashboard Statistics

## Technologies Used

- HTML
- CSS
- Bootstrap
- JavaScript
- Python
- Flask
- MySQL
- OpenPyXL
- ReportLab
- Chart.js
